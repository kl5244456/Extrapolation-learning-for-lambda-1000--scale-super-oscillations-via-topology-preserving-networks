# Extrapolation-learning for $\lambda/1000$-scale Super-oscillations via Topology-Preserving Networks
This repository contains the core implementation for the paper "Extrapolation-learning for $\lambda/1000$-scale super-oscillations via topology-preserving networks." The project leverages topology-preserving Neural Networks (PCNN) to design super-oscillatory fields with resolutions reaching the $\lambda/1000$ scale by learning and extrapolating the underlying analytic manifold of Chebyshev zeros.

🔬 OverviewTraditional super-oscillation design methods face significant computational challenges at extreme resolutions. This approach utilizes a Multi-Layer Perceptron (MLP) to map design parameters (ROI width $W$ and target resolution $\sigma$) to the complex roots (zeros) of the super-oscillatory function. By enforcing topology-preserving constraints, the network ensures that predicted zeros remain strictly on the unit circle $|z|=1$, maintaining physical feasibility even deep into the extrapolation regime.
